# Where the terminal marks come from

`terminals-light.svg` and `terminals-dark.svg`, the row in the README, use each project's own mark:

- iTerm2, Ghostty, WezTerm, kitty, tmux, Cursor, Windsurf and JetBrains: [Simple Icons](https://simpleicons.org) 16.38.0 (CC0), in each brand's colour from Simple Icons; the black marks turn light on a dark page.
- zellij: `assets/logo.svg` from [zellij-org/zellij](https://github.com/zellij-org/zellij) (MIT).
- Windows Terminal: `res/terminal/Terminal.svg` from [microsoft/terminal](https://github.com/microsoft/terminal) (MIT).
- VS Code: `vscode.svg` from the icons on [code.visualstudio.com/brand](https://code.visualstudio.com/brand).

The marks belong to their owners and stand here only to name the terminals Openbar reaches.

The label above this row and above the agents row ("18 agents", "11 terminals and editors") comes from `docs/assets/readme/section-label.py`. Run it again after regenerating either row; it recounts the marks.
