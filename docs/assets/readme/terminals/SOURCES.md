# Where the terminal marks come from

`terminals-light.svg` and `terminals-dark.svg`, the row in the README, use each project's own mark:

- iTerm2, Ghostty, WezTerm, kitty, tmux, Cursor, Windsurf, JetBrains and Docker: [Simple Icons](https://simpleicons.org) 16.38.0 (CC0), in each brand's colour from Simple Icons; the black marks turn light on a dark page.
- zellij: `assets/logo.svg` from [zellij-org/zellij](https://github.com/zellij-org/zellij) (MIT).
- Herdr: `assets/logo.svg` from [herdrdev/herdr](https://github.com/herdrdev/herdr) (Apache-2.0), as its own tile with rounded corners.
- Windows Terminal: `res/terminal/Terminal.svg` from [microsoft/terminal](https://github.com/microsoft/terminal) (MIT).
- VS Code: `vscode.svg` from the icons on [code.visualstudio.com/brand](https://code.visualstudio.com/brand).

The marks belong to their owners and stand here only to name the terminals and containers Openbar reaches.

The label above this row and above the agents row ("18 agents", "13 terminals, editors and containers") comes from `docs/assets/readme/section-label.py`. Run it again after regenerating either row; it recounts the marks.
