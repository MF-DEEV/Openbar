# Support

Openbar is free and open source, looked after on a best-effort basis. There's no support contract, but every issue and question gets read.

| You want to | Go to |
| --- | --- |
| Ask how something works | [Discussions, Q&A](https://github.com/MF-DEEV/Openbar/discussions/categories/q-a) |
| Suggest an idea | [Discussions, Ideas](https://github.com/MF-DEEV/Openbar/discussions/categories/ideas) or a [feature request](https://github.com/MF-DEEV/Openbar/issues/new/choose) |
| Report a bug | A [bug report](https://github.com/MF-DEEV/Openbar/issues/new/choose), after the [troubleshooting guide](docs/TROUBLESHOOTING.md) |
| Report a security issue | The [security policy](SECURITY.md). Never a public issue |
